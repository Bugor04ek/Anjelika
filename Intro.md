# Project `X`
## Структура  

### Consts.py

  Файл содержит все классы и константы.
- `dictionary_spinners` - словарь фильер/волок.
 
   Логика смены следующая (переход с 0.254 на 0.2795):

```
1. Снимаем 21-ую фильеру 0.26 диаметра (1 минута)
2. Снимаем 20-ую фильеру 0.2795 диаметра (1 минута)
3. Ставим 20-ую фильеру 0.2795 диаметра на последнее место 
и протаскиваем через не все проволочки (5 минут * количество проволочек)
```

- `QueueMultivare` - последовательность катушек на мультике. Считает время катушек в группе.
Выводит группы в эксель. 
Необходимо рассчитать время на смену фильер между группами катушек.

- `Bobbin` - катушка складывает в себе кабель одной группы, внутри группы не происходит перенастроек и не тратится время на фильеры.
- `Order` - пока что содержит всю инфу по заказу и все расчеты для мультика.
- `Mark` - марка кабеля с расшифровкой кабеля. Нужно доделать расшифровку на более детальную
- `ЗаданиеНаОборудование` - надо разработать задание для каждого оборудования
- `ЗаданиеНаМультик` - надо разобрать марку на несколько заказов на мультик на параметры, которые важны на мультике
```
1. Длина стренги 
2. Кол-во прядей
3. Кол-во проволочек
4. Диаметр
5. IDzak
```
